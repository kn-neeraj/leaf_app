# style_spec.md

## Font

- Primary font: **SF Pro Text** (system default)
- Code font: **SF Mono**
- Font switching not supported in v1

---

## Font Sizes

- Body text: **16–17 pt**
- H1: **30–32 pt**
- H2: **24–26 pt**
- H3: **20–22 pt**
- H4: **18–19 pt**
- Code blocks: **14–15 pt**

---

## Line Spacing & Layout

- Body line height: **1.55 – 1.65**
- Paragraph spacing: **0.8 – 1.0em**
- Lists: slightly tighter spacing than paragraphs
- Blockquotes: use secondary text and a soft leading border
- Max content width: **680 – 740 px**
- Content centered horizontally

---

## Colors

### Light Mode
- Text: `#1C1C1E`
- Background: `#FFFFFF`
- Secondary text: `#6E6E73`
- Accent (links, bullets): `#4DA3FF`

### Dark Mode
- Text: `#EDEDED`
- Background: `#0F0F10`
- Secondary text: `#9A9A9A`
- Accent (links, bullets): `#4DA3FF`

### Contrast guidance
- Avoid pure black/white in surfaces; prefer softer contrast for long reading sessions.

---

## Headings

- Clear visual hierarchy
- Heavier font weight, restrained size
- Generous top margin
- No underlines or decorative elements

---

## Code Blocks

- Font: **SF Mono**
- Subtle background contrast (2–4%)
- Rounded corners
- Horizontal scroll if needed
- No loud syntax coloring

---

## Images

- Max width equals content width
- Center aligned
- Maintain aspect ratio
- Subtle rounded corners

---

## Design Principle

> Typography should disappear; reading should feel calm and effortless.
